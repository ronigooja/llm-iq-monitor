Quick start

The base path is /monitor/. Add _shape=array to receive a JSON array. Parameters are strings; an empty or missing optional parameter means no filter.

curl 'https://iq.z0e.dev/monitor/ranking.json?dim=reasoning&_shape=array'

Pick the best model for a dimension by score, then latency:

const rows = await fetch('/monitor/ranking.json?dim=reasoning&_shape=array').then(r => r.json());
const best = rows.find(row => row.score != null);

Ranking is already ordered by score descending, then latency_p50 ascending; unknown values are null, never 0.

Queries

Click the Try it button to fetch the example and see the first 3 rows.

best

GETpublic

One row per capability, always six. Candidates are model × effort pairs with a score. Excluded models and candidates below min_availability are dropped; those within score_tolerance of the best score are kept; of those, the ones within price_tolerance of the cheapest are kept; the lowest median latency wins. model and effort are null when no candidate remains.

Parameters:
NameRequiredDescription
score_toleranceoptionalscore points admitted below the best score; default 0
price_toleranceoptionalpercent above the cheapest kept candidate; default 30
min_availabilityoptionalminimum probe availability (0–1) in the recent window; candidates without probe data are kept; 0 disables; default 0.9
excludeoptionalcomma-separated model-id keywords to exclude from every dimension
exclude_reasoningoptionalcomma-separated model-id keywords to exclude from this dimension only
exclude_codeoptionalcomma-separated model-id keywords to exclude from this dimension only
exclude_instructionoptionalcomma-separated model-id keywords to exclude from this dimension only
exclude_write_zhoptionalcomma-separated model-id keywords to exclude from this dimension only
exclude_write_enoptionalcomma-separated model-id keywords to exclude from this dimension only
exclude_uioptionalcomma-separated model-id keywords to exclude from this dimension only
Returned columns:
dim(dimension key)
use_when(when to use this dimension)
model(model id; null when no candidate is eligible)
effort(effort level; null when model is null)

Field semantics summary
  • score: 0–100.
  • latency_p50: time to solve in seconds.
  • quality: judged writing quality.
  • cost_per_correct: derived USD cost per correct result.
  • availability: share of successful probes, weighted by time, 0 to 1; null without probes.

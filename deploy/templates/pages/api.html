Quick start

The base path is /monitor/. Add _shape=array to receive a JSON array. Parameters are strings; an empty or missing optional parameter means no filter.

curl 'https://iq.z0e.dev/monitor/ranking.json?dim=reasoning&_shape=array'

Pick the best model for a dimension by score, then latency:

const rows = await fetch('/monitor/ranking.json?dim=reasoning&_shape=array').then(r => r.json());
const best = rows.find(row => row.score != null);

Ranking is already ordered by score descending, then latency_p50 ascending; unknown values are null, never 0.

Queries

Each example opens in a new tab. Use the Try it button to fetch the example and inspect its first three rows.

ranking

Ranking for one capability: the latest finished run of each model × effort that ran the dimension, ordered by score descending, then latency_p50 ascending, with null scores last.

Parameters: dim (required: a dimension key, including write_zh and write_en); effort (optional).

Returned columns: rank (rank; null when the score is null); model (model id); effort (effort level); run_id (run id); finished_at (finish time, Unix seconds UTC); dataset_version (dataset version); status (run status); availability (successful requests divided by total requests); score (score from 0 to 100); quality (judged writing quality; null for other dimensions); latency_p50 (median time to solve in seconds); latency_p95 (95th-percentile time to solve in seconds); ttft_p50 (median time to first token in seconds); time_total (total measured time in seconds); n (number of requests); n_err (number of errors); cost_usd (derived run cost in USD); cost_per_correct (derived USD cost per correct result).

series

          
History points, time ascending, at most 2000 rows.

          
Parameters: model, effort, dim (all required); from, to, dataset_version (optional).

          
Returned columns: t (finish or rating time, Unix seconds UTC); run_id (run id); dataset_version (dataset version); score (score from 0 to 100); quality (judged writing quality; null for other dimensions); latency_p50 (median time to solve in seconds); latency_p95 (95th-percentile time to solve in seconds); ttft_p50 (median time to first token in seconds); time_total (total measured time in seconds); availability (successful requests divided by total requests); cost_per_correct (derived USD cost per correct result).

models

          
One row per model × effort that has finished runs.

          
Parameters: none.

          
Returned columns: model (model id); effort (effort level); active (whether the model is active); dims (dimensions with data, comma-separated); last_finished_at (last finish time, Unix seconds UTC); last_status (last run status).

ui_samples

          
Latest SVG samples with stars, newest first, at most 200 rows.

          
Parameters: model, effort (optional).

          
Returned columns: sample_id (sample id); model (model id); effort (effort level); prompt_key (prompt identifier); prompt (prompt text); svg (SVG, null for replaced samples); valid (whether the sample is valid); stars (rating from 1 to 10); created_at (creation time, Unix seconds UTC).

Sets the stars of one sample; the only write endpoint.

          
Needs the rating key, POST, not for general use. The key is held by the site owner.

          
Parameters: sample_id, stars (POST, key required).

          
Returned columns: ok (true when the request is accepted); message (result message).
